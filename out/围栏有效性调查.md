# 围栏有效性调查 · 怎么保证「不是自己骗自己」

> 用户问：「你怎么能保证这个栏杆是有效的，而不是自己骗自己？」
>
> 这份文档记录调查过程、发现的两处自欺、以及唯一能站得住的验证方法。
> 全部结论带可重跑命令。

---

## 一、先承认：报「拦住 11/12」本身证明不了任何事

`tools/fence_acceptance.py` 说 12 个真缺陷样本拦住 11 个、误报 0 —— 这个数字有三处可以被自己操控：

| 可疑处 | 为什么可疑 |
|---|---|
| **样本是我选的** | 12 个全来自「我踩过的坑」。已知缺陷的回放 ≠ 未知缺陷的检出率 |
| **期望是我定的** | 「S1 应放行、S2 应拦住」也只是我的理解，没有独立标准 |
| **判定是我写的** | `blocked=True/False` 由我写的样本函数返回。**我可以直接 `return True`** |

前两条无法根除（只有一个作者、一个语料）。**第三条能根除，而且它是最要命的一条。**

---

## 二、本轮自查：两处自欺，都是第三条

### 自欺 1 · 样本复制了围栏逻辑

`S3/S4/S5/S6/S12` 原来把围栏的正则和判断**抄进样本里**：

```python
# 错：样本自己写一遍正则
got = [int(m) for m in re.findall(r"(\d+)\s+checks", tex)]
bad = [g for g in got if g != want]
```

后果：**把真围栏改坏，样本照样报「拦住」** —— 它测的是自己抄的副本。

### 自欺 2 · 修了「调真围栏」却只读当前状态

改完以后 `S6/S12` 变成调用 `arch_invariants.i12()/i11()`，但仍报「拦住」。

**变异测试立刻抓到**：把 `i11` 改成「永远成立」，`S12` 还是「拦住」。

原因：样本读的是**围栏的当前状态**（「现在没有越界探针」= 成立），而不是**构造一个越界探针看它报不报**。

> 这和更早的 `S3/S4/S5` 是同一个病：那时它们读的是「已被我修好的论文」，于是报「漏检」——也是假警报。

**正确的样本必须同时满足两条：构造缺陷 + 调用真围栏。缺一条就是假测试。**

---

## 三、唯一站得住的验证：变异测试

把围栏**故意改坏**（让它永远通过），再看对应的接受测试样本是否变成「漏检」。

- 改坏了 → 样本报错 → 测试真的在测围栏
- 改坏了 → 样本仍「拦住」→ **假测试**

```powershell
python tools/fence_mutation.py
```

### 实测结果（本轮）

```
变异测试：4 道围栏
  [敏感] freeze._match_written 永远放行   变异后：blocked=False（敏感✓）
  [敏感] arch_invariants.i11 永远成立      变异后：blocked=False（敏感✓）
  [敏感] arch_invariants.i12 永远成立      变异后：blocked=False（敏感✓）
  [敏感] redteam.check 永远 PASS          变异后：blocked=False（敏感✓）

假测试：0 / 4
```

**这是唯一一个「改坏就报错」的检查**，也是它区分于「自查」的地方。

### 变异器自己也会错

第一次跑报「2 个假测试」，实际是**变异器写错了**：`i11(spec=...)` 带参数，而变异写成 `lambda: ...` → `TypeError` 被当成「没变化」。

修成 `lambda *a, **k: ...` 后 4/4 敏感。

> **又是「检查脚本报错先验证脚本」**。这条规矩在这个仓库里已经救过 8 次。

## 五、这一轮靠围栏抓到的新缺陷（围栏的产出）

I12 一上线就抓出 22 个旧图，顺着查下去发现一个**从没人报过的真缺陷**：

| 项 | 内容 |
|---|---|
| 现象 | `fig8_pages_figs.pdf` 从 11-10 起没更新过 |
| 原因 | `make_final_figs.fig_pages_figs()` 依赖 `data.json` 的 `n_fig_env` 字段，**而这个字段从来没被采集过**（备份里也没有）→ `if not rows: return` 静默跳过 |
| 影响 | 一张**孤儿图**：论文引用了它一次，内容永远是旧的，`gate.figures` 报 8.0/10 A20 全优 |
| 修法 | `collect_paper_data.py` 补采 `n_fig_env`（从源文件数 `\begin{figure}`，23 题范围 4–12），重画 |
| 痕迹 | `arch_invariants.py` I12；`collect_paper_data.py` 的注释 |

**这条不是靠「审代码」发现的，是靠「图不许旧于数据」这条机械不变式逼出来的。**

## 六、写进规矩（不只是这一次）

`AGENTS.md` 已加：**任何「围栏有效」的断言，必须附变异测试结果**。

具体要求：

| 要说的话 | 必须附的证据 |
|---|---|
| 「这道门能拦住 X」 | 一个构造出来的 X 样本 + 该门报错的输出 |
| 「这套判据有效」 | `python tools/fence_mutation.py` 的「假测试 0/N」 |
| 「测试通过了」 | 说明样本是**构造缺陷**还是**读当前状态**；后者不算测试 |

**禁止的写法**：「我检查过了，没问题」「gate 全绿，所以是对的」「36/36 可溯源」（不说明分母口径就是废话）。

## 八、证明的边界（不能证明到「真」）

### 逻辑上做不到

明希豪森三难：任何证明要么**无穷倒退**、要么**循环**、要么**在某个公理上停**。

```
围栏有效 ← 变异测试证明
变异测试有效 ← ？
  ← 再写一个测试 → 无穷倒退
  ← 或者停在这里：「这几行输出任何人重跑都一样」
```

**停止点：可复跑的命令 + 可对比的数字。**

再往下一层证明不了：解释器是否正确执行了这段代码、文件系统是否如它声称那样保存了字节、输出是否被截断。「任何人做任何验证都会停在同一层」，所以这不是本项目的缺陷，是证明的本性。

### 我更该被怀疑的地方：我说过 8 次假话

| # | 我说过 | 实际 | 现在由什么拦 |
|---|---|---|---|
| 1 | 「40 条 finding 且均已关闭」 | `resolved` 写的是「未处理」 | `_disposition` 占位词黑名单 |
| 2 | 「七板七角色，覆盖完整」 | 论文 12 节只审 7 板 | `redteam.check` 按 `\section` 解析 |
| 3 | 「37/37 可溯源」 | 整数完全不判 | gate 显式打「另有 N 个整数未纳入判定」+ `live_vars_check` |
| 4 | 「fig16 是当前数据」 | 5082 词 / 旧章节名，实际 9768 | `I12` 图不旧于数据 |
| 5 | 「figures 8.0/10，A20 全优」 | `fig8` 是孤儿图，从 11-10 未更新 | `I12` + `n_fig_env` 采集 |
| 6 | 「拦住 11/12」第一次 | 样本复制了围栏逻辑 | `fence_mutation` |
| 7 | 「拦住 11/12」第二次 | 样本只读当前状态 | `fence_mutation` |
| 8 | 「I1/I9 不成立」 | 是检验器写错，架构没错 | 检验器按「用途」而非「函数名」判 |

**所以「这次是真的」这句话本身没有可信度。** 唯一有可信度的是「这条命令你重跑，得到这些数字」。

## 九、那这一整套的意义是什么

**不是「证明为真」（做不到），是「让错误更早被发现，并且留得下痕迹」。**

### 意义 1 · 错误从「只在人脑子里对」变成「有命令能查」

| 12 轮前 | 现在 |
|---|---|
| 论文写 `1482 untraced / 1053 D_computed`，实际 263 / 28，没有任何机制能发现 | `python tools/live_vars_check.py` 一行报不一致 |
| 「七板七角色」看着像覆盖完整 | `redteam.py roster` 按 `\section` 解析，少一板就 FAIL |
| `fig16` 画的是两版前的数据 | `I12` 一条不变式，22 个旧图立刻现形 |
| 同一产物在 gate 与 verify 判出 PASS 116/116 vs 88.0% | `I1` 保证精度口径唯一 |

### 意义 2 · 8 次假话，8 次被抓，8 次变成断言

这才是可验证的部分 —— **不是「我不会错」，是「错了会被抓，且抓完变成代码」**。

抓它们的东西各不相同：红队、变异测试、飞轮台账曲线、架构不变式、以及最难堪的一种——**我自己跑一条命令时数字对不上**。

### 意义 3 · 下一个会话不用重新踩这 8 个坑

`AGENTS.md` 里现在有：每环的骗法（8 条）、假话清单（8 条）、举证要求、证明的停止点。

**可继承性比「这次对了」重要得多。** 一个人做对一次没有价值；把「怎么错」写成下一个会话一进来就能读的规矩，才有。

### 意义 4 · 判定口径从「我觉得」变成「命令 + 数字」

| 以前 | 现在 |
|---|---|
| 「论文数字都对得上」 | `numbers 37/37，另有 160 个整数未纳入判定`（分母和口径都写着） |
| 「红队审过了」 | `12 板 12 角色，40 条：fixed 14 / blocked 2 / open 24` |
| 「架构没问题」 | `不成立：0 / 12` |
| 「测试通过了」 | `假测试：0 / 4`（变异测试，不是自查） |

### 意义归零的条件（必须说）

1. **没人跑这些命令** —— 台账、红队报告、不变式就只是文件
2. **数字对不上时没人管** —— 红项可以永远红着
3. **骗过的记录被擦掉** —— 那这套东西就退化成「我说了算」

这三条里任何一条成立，上面的意义全部作废。**飞轮不会自己转。**
